## 导入与核对

`scripts/primary-math-directory-extract.py` 逐行读取附件内目录，保存课程原名、知识点名称、年级、版本、类型及章节；「核对说明」记录工作簿、工作表和行号。目录 ID 由来源定位生成，重复运行不会重复创建。
