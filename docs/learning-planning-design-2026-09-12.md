# 学情规划界面优化

## 设计依据

- 使用已安装的 `design-taste-frontend`，按现有系统的局部改版方式实施。
- 场景是销售老师日常录入资料、阅读诊断和向家长沟通，采用紧凑的教育诊断工作台布局。
- 原界面导航为紫色、报告为绿色，输入区留白分散、信息层级较弱。本次统一为白色及浅灰底、深绿色主色，琥珀色辅助标识报告资料和诊断总结。
- 保留现有系统字体、相机标识、导航名称、页面路径、表单字段顺序和权限边界。沿用 shadcn 与 lucide，无新增依赖。
- 设计参数：布局变化 3/10、动效 2/10、信息密度 6/10。减少动态效果，支持系统减少动态效果设置。

## 本次调整

1. 公共导航明确当前模块，标题与洋葱学园归属统一呈现。
2. 学生信息集中排列；观看记录与学情报告并列，手机上依次排列，增加资料添加状态和备注字数。
3. 家长话术优先呈现，诊断总结独立强调，五步电话话术以编号和连接线组织。
4. 电话和微信仍共用同一份报告；微信看板突出阶段目标、验收标准和解决方案，导出长图同步配色。
5. 手机端复制按钮收紧为图标，保留可访问名称、提示与成功反馈；修复年级未选择时缺少占位文字的问题。

## 验证记录

- 本地浏览器检查 1280px 桌面、390px 手机及 320px 窄屏；检查输入页、电话页、微信看板和图片导出预览，无横向溢出。
- 使用明确标记为“规划验证学生（非客户）”的测试报告，未调用模型、未使用客户资料；验证后按准确记录 ID 清理。
- 验证必填状态、年级选择、批量添加两张截图、移除截图、资料状态、复制反馈、默认折叠与展开依据、新建规划。
- 微信长图成功渲染为 900 × 2261 像素，预览可打开；报告内容仍来自同一个存储结果。
- 公共试卷分析入口正常，导航路径和权限判断保持原实现。
- `npm run lint`、生产构建与 6 项既有学情规划测试通过。构建仍有项目已有的大文件分包提示。

本次为界面调整，未修改模型、提示词、课程检索、报告链接加密、任务接口和业务存储协议。
