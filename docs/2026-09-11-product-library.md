# 产品库与话术替换（本地完成，未发布）

## 来源与范围

- 唯一产品事实来源：[洋葱学园产品能力库（诊断承接版）](https://guanghe.feishu.cn/docx/KmT1diV1BozRUnxf09acxsIInvd)。
- 来源内容于 2026-09-10 通过已登录浏览器逐节读取；2026-09-11 完成本地接入。保留 29 个 CAP 能力编号、适用问题、路径、验收及边界的审阅快照。
- 本次不发布、不推送代码，不变更线上版本。历史报告保留原内容；仅后续用本地新代码生成的报告适用新规则。
- 当前不是实时文档同步。原文更新后，需重新核对并更新快照及日期；文档 API 的用户身份尚缺 docx:document:readonly 权限，本次未新增运行时文档依赖。

## 变更

1. 替换旧分析系统提示词，移除“下危机、画大饼、固定产品卖点、默认体验卡”等表达。保留确认错题、正误分开、图片质量、完整备注、知识点和课程依据规则。
2. 同一次分析请求结合学情，从可用能力中选择 2—4 个编号。一个主目标、最多两个次目标，产品路径覆盖学习、练习、验证、复盘至少三个环节；证据不足时允许不推荐。
3. 家长话术使用“具体表现、优先问题、少量适配能力与顺序、复测指标”。课程类型、典型短课特点和具体视频目录分别使用，不把 5—8 分钟典型短课写成固定视频时长或学会时限。
4. 推荐正文按经校验的编号读取同一份产品库，保留名称、使用路径、验收、适用边界和来源。拒绝不存在的编号、跨学段学科能力、过多或不足的能力组合；不通过时使用待核实话术，不沿用未经核实的产品文案。
5. 停止读取旧产品映射表来生成报告，移除内置旧产品/工具模块的兜底拼接。保留原表及管理接口，未修改业务数据。
6. 会员档位保留兼容字段但填“待定”：本文是能力库，不能据错题数量、学科数量或一次全对自动推断会员权益、全科会员或培优套餐。
7. 初识别不携带产品库，不增加模型调用；“知识点关键词匹配 1—2 节课程”流程继续独立运行。

## 使用边界

产品覆盖、设备入口、套餐权益、辅导服务和具体视频时长仍按文档要求“使用前核实”。程序校验编号与学段学科，模型负责判断问题与能力是否适配；自由话术的事实与教学判断仍应由销售复核，自动化测试不等于对所有生成结果的保证。

## 验证

- 40 项测试通过，覆盖鉴权、任务保存、照片复用、知识点/课程流程，以及产品编号、范围、数量校验、旧卖点替换、跟进提示格式与内部编号清理。
- TypeScript、ESLint、Stylelint 与本地生产构建通过；构建保留已有的大包大小及 Vite 配置提示。
- 可用 `test/diagnosis-product-live.cjs --model-only tmp/physics-sample.jpg` 进行单次真实模型验证，仅使用合成试卷，不写飞书业务记录、不发布。
- 真实合成物理卷验证通过：选择“同步概念课 → 专项突破 → AI 错题本”，家长话术对应进率混淆，跟进提示要求核实教材/设备权益并约定复测。单次模型请求约 13 秒，4199 输入 token、942 输出 token；不是端到端耗时承诺。
- 实测发现模型可能把跟进提示返回为数组或遗漏，也可能把 CAP 编号混入自然语言。已兼容最多三条跟进提示、补充文档依据的缺失回退，并在家长话术/跟进/计划中移除内部编号；原始模型结果仍保留编号用于溯源。

实现入口：`server/modules/diagnosis-gateway/diagnosis-product-library.ts`、`vision.service.ts`、`diagnosis-recommendation.ts`。
