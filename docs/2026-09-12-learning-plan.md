# 学情规划交付与验收

## 本次范围

用户已授权将本次规划页面与此前产品库、长图匹配、数学课程目录的本地修改一起发布。发布结果以妙搭 release 状态和线上复测为准。

- 输入学生姓名、实际年级、诊断科目和规划属性；观看记录与学情报告各支持文字、截图粘贴、批量选择及拖入，共最多 6 张、12 MB。备注进入分析。
- 洋葱报告链接通过服务端固定地址读取累计统计；不把累计数据当成近期、逐题或单一知识点掌握率。明细需要补充截图。
- 一次任务保存一份报告，电话与微信只切换展示。家长话术置顶；支持全文、总结、五个沟通步骤分别复制。
- 电话按共鸣开场、问诊定位、风险讲透、解决方案承接、推进下一步展开，专业依据默认折叠。
- 微信展示学生信息、结论、7 天/1 个月/本学期计划、40/60 建议比例、解决方案和已核对课程，支持 PNG 整图导出。
- 电话和微信共用知识点、使用功能、使用方法、适用原因、验收标准五列方案；基础未通过短测时先补基础，再过渡到比例建议。

## 数据与调用

延续平台登录和 sales/admin 授权、飞书任务表与 qwen3.5-omni-plus。两次模型调用分别用于资料事实提取、统一报告生成；课程检索夹在两者之间，第二次不重复传截图，切换页面、复制、导出和读取任务不调用模型。

知识点按实际年级、科目检索目录，产品按审核能力库限定，服务端解析真实能力编号和边界。观看时间不当观看时长；观看过不等于掌握；跨年级记录需问诊确认。缺少目录时不编造课程。

链接限定洋葱报告 origin 和 path，不接受用户指定接口或学生身份。令牌仅用于固定上游请求，不进入模型或任务报告。平台网关仍会记录请求正文，因此链接由浏览器使用 Web Crypto 的 RSA-OAEP/SHA-256 与 AES-256-GCM 加密后提交；密文绑定登录用户并在 2 分钟内有效，服务端拒绝明文、过期及篡改请求。私钥仅在服务端环境变量。规划接口保留平台 base path、CSRF 和登录凭证。规划截图不额外业务存档，仅保存识别事实与生成报告；平台日志留存由平台管理。

新增接口：`GET /api/diagnosis/learning/source-key`、`POST /api/diagnosis/learning/report-source`、`POST /api/diagnosis/learning/plans`、`GET /api/diagnosis/learning/plans/by-request/:requestId`、`GET /api/diagnosis/learning/plans/:jobId`。读取只允许任务本人，重试复用请求编号，服务端记录阶段耗时。运行 `node scripts/learning-source-key.cjs --apply` 为 dev/online 配置同一把安全读取密钥，已有密钥时复用，不随服务重启变更。

- 66 项自动测试通过，覆盖原诊断、长图、数学、截图输入，以及规划权限、幂等、资料验证、额外关键词归一化、产品白名单、单报告复用、导出转义、链接限制与浏览器/服务端加密往返及反例。
- TypeScript、ESLint、Stylelint 与生产构建通过；平台现有打包体积提示保留。
- 使用两张合成截图完成真实模型和飞书链路，未用客户截图测试。成功样本：证据 4.1 秒、目录 1.2 秒、报告 22.7 秒、保存 1.4 秒，总服务耗时约 32 秒。单样本不代表 P95 或承诺响应时间。
- 桌面与 390px 手机布局验证无横向溢出；复制全文、总结、5 段话术与家长话术成功；专业依据初始收起。
- 微信长图实测 900×3216 PNG，整图非空、内容完整、名称含学生名，可下载。两种视图使用同一已保存报告。
- 首轮发现模型返回过多关键词造成失败，现对有效关键词保留前三个；发现内部字段名进入正文，现统一转换并加强提示词。
- 初次线上链接验证曾产生 1 条含临时令牌的平台网关请求日志，应用关闭请求体日志未覆盖网关。随后改为端到端的链接加密载荷；历史网关日志无法由本应用删除，需平台管理员按平台留存规则处理。本文不记录原令牌。

## 试用限制与下一步

报告是基于当前资料的初步学习建议，销售需核实学生归属、教材、学校进度和账号权益。报告链接可能过期，失败时使用截图。任务在应用进程内执行，重启可能中断；15 分钟无结果视为中断，可重新生成。

下周唯一主目标：完成 10 个匿名化案例的销售试用复核，交付评审记录。验收每例均能从原始证据追溯结论、推荐功能和课程，家长话术能直接使用，记录生成耗时和销售修改点。业务负责人负责销售试用与评价，开发负责失败修复；建议截止 2026-09-18。
