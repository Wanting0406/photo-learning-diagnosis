# 中高考长图显示修复

## 原因

- 原前端仅在试卷/作业分析的“确认错题”区加载长图，学情规划未接入。
- 重新打开分析任务只恢复诊断报告，不恢复识别区；旧匹配接口也拒绝分析任务。
- 数据和线上表配置正常：51 张已审核原图、191 条可用知识点映射。
- 当前映射覆盖中考数学/物理/化学，高考数学/物理/化学/生物。课程入库不等于同科目的宣传长图已建立映射。

## 修复

- 学情规划新增 GET `/api/diagnosis/learning/plans/:jobId/materials`，返回现有 `MaterialMatchesResult`。
- 先验证当前用户拥有已完成任务，再以报告已保存的知识点匹配；不新增模型调用。
- 电话和微信视图下方共用异步长图区，不写入家长微信看板导出内容。
- 诊断报告区域同样加载长图。旧分析任务按报告知识点匹配，新任务同时保留初识别依据。
- 原有学科学段隔离、已审核限制、最多三张、横竖版去重和原图权限校验保持有效。

## 验证

- 93 项回归测试通过，覆盖旧分析报告、规划任务归属、未完成任务、素材故障隔离及零额外模型调用。
- ESLint、前后端 TypeScript、Stylelint、生产构建通过。
- 真实飞书索引读取成功；高三物理“区分位移和路程”返回两张 2026 高考物理海报，缩略图读取成功。
- 无已审核映射的学科或具体知识点仍返回无可靠结果，不扩大关键词以强行推荐。
