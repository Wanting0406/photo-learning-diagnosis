## 匹配与缓存

- 两个诊断入口共用目录读取与匹配，新增政治学科输入和校验。
- 课程显示名称、学段或明确年级、册别、版本、类型、地区及来源。模型输入保留必要册别和地区，不追加原始目录文件或整库内容。
- 高中同步课只注明必修/选择性必修的，保留册别，按高中学段匹配并提示核对学习进度，不编造具体年级。
- 高一高二重难点目录按来源文件夹限定高一、高二；高中数学一轮、二轮及真题继续仅高三，物化生英培优沿用用户已确认的高一至高三范围。
- 小学语文低/中/高段按常规一二/三四/五六年级组织，并保存规则依据；未细分年级的课程使用来源学段。
- 新中考数学保留 32 个区域课程包。明确地区时筛选对应区域；地区未明时只使用标为「本地化」的记录，并提示核对地区。
- 主知识点精确或保守包含匹配；辅助关键词仅精确匹配标题或来源行的小节标签。不得用整章名称为所有视频虚构知识点。
- 每次最多返回两节课程，无可靠命中不强推。跨学科、跨学段及高三限制保持。
- 三张表并发预加载，各自缓存，10 分钟有效、5 分钟起后台刷新；刷新合并并发、整表完整后替换。读取上限每表 30000 行，避免原先 10000 行上限截断初中目录。
- 不增加在线模型调用。

- `scripts/all-course-directory-extract.py`：只读附件内所有工作表，保留目录及来源定位。
- `scripts/all-course-directory-import.cjs`：`--plan`/`--apply`/`--verify`，来源 ID 幂等、保留人工修改、逐字段回读核对。读取可以重试，写入失败后重新核对已创建 ID 再续传，不盲目重试写入。
